Traits for the multiplication of vectors and matrices by abstract matrices (i.e., linear operators), with implementations for generic OxiBLAS matrices.

Oct. 15, 2026, H.-A. L.

Only the operators are abstract; vector operands and results are slices, matrix operands and results are OxiBLAS matrices.

Writing an algorithm in terms of these abstract operators enables users of that algorithm to provide their own specialized methods for the actual operator.

Using such an algorithm requires the implementation of the traits MatrixOps1 or MatrixOps2 or both (= MatrixOps). As examples, such implementations are provided for generic matrices and for diagonal matrices.

Trait MatrixOps1 defines the following methods:

nrows:                  number of rows
ncols:                  number of columns
mult_vct:               vct_c =  self * vct_b
mult_vct_addto:         vct_c += self * vct_b
mult_vct_scaled_addto:  vct_c += alpha * self * mat_b + beta * vct_c
tmult_vct:              vct_c =  self_t * vct_b
tmult_vct_addto:        vct_c += self_t * vct_b
tmult_vct_scaled_addto: vct_c += alpha * self_t * mat_b + beta * vct_c

where `vct_` denotes a vector (= a slice of scalars), `_t` means transposed
and `self` is the abstract matrix.

Trait MatrixOps2 defines the following methods:

mult_mat:                mat_c =  self * mat_b
mult_mat_addto:          mat_c += self * mat_b
mult_mat_scaled_addto:   mat_c =  alpha * self * mat_b + beta * mat_c
tmult_mat:               mat_c =  self_t * mat_b
tmult_mat_addto:         mat_c += self_t * mat_b
tmult_mat_scaled_addto:  mat_c =  alpha * self_t * mat_b + beta * mat_c

where `mat_` denotes an OxiBLAS matrix, `_t` means transposed, 
and `self` is the abstract matrix.


Example: vct_y = mat2 * mat1 * vct_x with abstract mat1 and mat2:

use oxiblas::prelude::*;
mod matrixops;
use matrixops::*;

fn mult_mult_vct(
	mat2: &dyn MatrixOps1<f64>,
	mat1: &dyn MatrixOps1<f64>,
	vct_x: &[f64],
	vct_y: &mut[f64],
	vct_wsp: &mut[f64], // workspace with same size as vct_x and vct_y
) {
	mat1.mult_vct(vct_x, vct_wsp);
	mat2.mult_vct(vct_wsp, vct_y);
}

let mat_a = Mat::from_rows( &[
   	&[   1.0,   2.0 ],
    &[ 100.0, 200.0 ],
   	]);
let mat_b = DiagonalMatrixOps {
    	diag: &[ 1.0, 30.0 ],
	};
let vct_x = &[ 10.0, 0.1];
let vct_y = &mut[ 0.0; 2];
let vct_wsp = &mut[ 0.0; 2];
 
// vct_y = mat_a * mat_b * vct_x:
mult_mult_vct( &mat_a.as_ref(), &mat_b, vct_x, vct_y, vct_wsp );
 
// vct_y = mat_b * mat_a * vct_x:
mult_mult_vct( &mat_b, &mat_a.as_ref(), vct_x, vct_y, vct_wsp );
